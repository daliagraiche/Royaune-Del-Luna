# Royaume Del Luna 

**Royaume Del Luna** is a restaurant showcase website developed using HTML, CSS, and JavaScript.

The website presents a fictional restaurant through an elegant interface, highlighting its menu, specialties, and event services.

## Features

- **Home Page:** Introduction to the restaurant and its concept.
- **Menu:** Presentation of the restaurant's dishes and food categories.
- **Contact:** Contact information and reservation section.
- **Specialties:** Italian dishes, fast food, and desserts.
- **Events:** Dedicated sections for birthdays, graduation celebrations, and engagements.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Launch `Accueil.html` in your web browser.

No installation is required.
